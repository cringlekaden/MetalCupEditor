# Contributing

Keep changes focused on the editor boundary. Build the relevant scheme and test the changed workflow before opening a pull request. Do not modify engine internals from this repository, change serialized formats without review, or commit user projects, Application Support data, caches, Derived Data, Xcode user state, or generated output.

For documentation changes, update the appropriate handbook page, verify links, and keep experimental behavior confined to `Docs/development-status.md`.
