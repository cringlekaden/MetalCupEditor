# MetalCupEditor application source

This directory contains the macOS application target: `App/`, project management, `EditorCore/`, `EditorUI/`, bundled resources, and vendored ImGui/ImGuizmo integrations. Public user documentation is maintained at the repository [handbook](../Docs/README.md); renderer/runtime architecture belongs to [MetalCupEngine](https://github.com/cringlekaden/MetalCupEngine/tree/main/Docs).
